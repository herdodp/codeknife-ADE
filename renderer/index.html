About Codeknife

Codeknife is an Agentic Development Environment with a Monaco editor and an integrated AI assistant.

The editor includes an interactive PowerShell terminal, bundled Python analysis via Pyright, and optional clangd, gopls, and rust-analyzer integration. The VS Code extension marketplace and debugger are not included.
